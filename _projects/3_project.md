A CNN-based deep learning framework that detects Parkinson's disease from **keystroke dynamics** — the timing patterns in how someone types — achieving 95%+ accuracy. Because it only needs ordinary typing behaviour, it points at screening that can happen passively, without a clinical test.

Source and setup instructions are on [GitHub](https://github.com/Jithin06/digital_phenotyping).
